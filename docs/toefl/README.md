# 托福纯源码接入

托福浏览器源码在 `front-end/toefl/`，服务端、原创匿名样例和检查工具在 `back-end/toefl/`，本目录保存模块文档。SAT 仍由独立目录维护。供统一入口使用的页面跳转已提供，见 [入口约定](ENTRY_INTERFACE.md)；统一 Python 服务现已接入 Study Space 账号与托福学习状态同步；原私有云站保持独立。下述独立匿名构建和预览不部署网站，也不启用账号。

## 本地运行

需要 Node.js 22.13 或更高版本。模块没有第三方 npm 依赖，无需先安装依赖。

在仓库根目录运行，Windows 与 macOS 使用相同命令：

```sh
node back-end/toefl/scripts/check-source.mjs
node back-end/toefl/scripts/build.mjs
node back-end/toefl/scripts/test.mjs
node back-end/toefl/scripts/preview.mjs
```

预览地址为 `http://127.0.0.1:8788/`，只监听本机。首页明确标记匿名样例；题目是原创测试材料，听力与口语音频仅为合成提示音，不代表来源原音频。关闭终端或按 Ctrl+C 停止预览。

构建输出位于忽略提交的 `local-data/builds/toefl/`。其中 `preview/` 仅用于匿名界面预览，`cloud-test/` 供原有后端回归在内存数据库中运行；两者都不是正式部署包。测试使用替身 AI，不调用外部模型或正式数据库。

也可进入 `back-end/toefl/` 后使用 `node scripts/<命令>.mjs`。构建会重新生成 `local-data/builds/toefl/`，不要把手工编辑的题目或私人资源存放在构建目录。

| 目录 | 内容 |

## 上传边界与清单维护

上述前端、后端、文档三个目录各自的 `.gitignore` 默认忽略新文件，只放行逐项审查的源码和匿名样例；当前清单检查同时核对文件摘要、匿名数据和 Git 已跟踪范围，可发现强制加入的清单外文件。它还检查常见访问令牌、私钥、开发电脑路径与破坏性 SQL；静态扫描不能替代人工审查。

源码清单的 `schema_version: 2`、`path_base: repository-root` 和三个固定目录范围用于当前布局；原导出摘要仍保留历史路径。修改已有源码后，先审查差异，再运行 `node back-end/toefl/scripts/check-source.mjs --update` 更新清单摘要。新增文件须明确加入忽略规则和清单；命令不会自动扫描目录收集新文件。构建输出、音频、录音、题库、HAR、密钥及正式部署配置不得加入清单。

## 服务端配置边界

匿名构建和预览无需配置变量，也不需要 Cloudflare 登录。`back-end/toefl/.env.example` 只说明原 Worker 的变量名，不会自动加载或连接服务。

原 Worker 需要 `DB`（D1）、`ASSETS`（加密资源）与可选 `AI` bindings。`CONTENT_KEY` 为服务端 AES 密钥；`ADMIN_USERNAME`、`PASSWORD_SALT`、`PASSWORD_HASH` 是原系统兼容初始化参数；正式迁移不能用它们重置既有账号。`ENABLE_AI`、`ASSESSMENT_PROVIDER` 和模型名称控制评分服务，Groq 仅在显式配置服务端 `GROQ_API_KEY` 后使用。配置值不得放入浏览器或提交到 Git。

本仓库没有真实 binding 标识、密钥、首次建库或历史清空命令。SQL 文件是结构参考，本地检查只在内存数据库中执行；普通服务器部署、正式资源获取和账号迁移均需独立任务。

## 公共接口的本地适配

`back-end/toefl/integration/platform-adapter.mjs` 提供 `mapQuestion(record)` 和 `mapAttempt(attempt, context, questions)`，落实现有架构草案中的考试命名空间、题目内容版本、独立练习编号、UTC 时间和同账号同版本重试键。

`context.userId` 必须由未来调用方从服务端已验证身份中取得；映射函数本身不提供身份认证。它忽略作答对象自带的用户 ID，并把客户端成绩标为 `client_reported`。统一平台的账号与原生托福状态保存现已通过独立桥接接入；本映射草案仍未用作通用练习报告保存 API，也不宣称已有服务端成绩复核。

题目原始 ID、日期版本及练习原始结构保留。接口名和字段目前只是可测试的适配草案，需与 SAT 负责人确认后冻结。现有前端和云端接口没有因此改名或自动迁移。

## 首页与考试记录

托福主页融合新版工作台的留白、圆角和卡片层次与原托福的练习操作，使用绿色主卡、真实统计、四项学习工具和最近考试记录。首页以 Start Practice 统一进入专项练习，内部继续保留四科、题型、搜索筛选、计时、随机组卷和作答／解析切换；整套模考单独进入。未完成练习优先显示，返回题库时保留既有科目和筛选。首页保留新版简洁顶部；进入题库、模考、错题、词汇、记录与进度等次级页面后显示绿色导航条，右侧只保留新版学习入口（独立平台预览）、账号菜单与设置，旧搜索／设置／账号工具不再渲染。窄屏导航单独横向滚动，不挤占右侧控件。账号菜单与设置使用现有身份和设备偏好。考试与解析仍使用独立的青绿色考试栏，不受管理页面的暖白背景影响。

## 进行中练习与账号管理

进行中的练习在区域标题右侧提供“管理”，弹层可勾选、全选和取消所选；二次确认后丢弃未完成作答，不产生考试记录。持久化失败保留选择与草稿，取消标记随原草稿状态同步，旧设备的迟到写入不能恢复已取消练习。已提交报告保留。

私人站同账号仅保留一个有效登录会话，新浏览器成功登录会使旧会话失效，同浏览器标签页继续共享。管理员账号详情提供删除普通账号的操作，要求准确输入用户名确认；服务端禁止删自身或管理员，原子清理目标账号的私人数据。规则见 `back-end/toefl/AGENTS.md`、`front-end/toefl/AGENTS.md` 及仓库的托福产品化计划。统一平台另用公共会话与后台权限实现同一规则。


## Study Space 统一账号接入

从统一服务的 `/toefl/` 进入时，首页与托福共用服务端 `HttpOnly` 会话。账号名称、角色与账号 ID 来自服务端核验；浏览器 URL 不传递身份。未登录、会话失效或在另一个浏览器成功登录后，页面返回统一登录页。托福退出登录会先尝试同步待办，再调用平台退出，同时通知同源其他标签页。

`front-end/web/toefl-bridge.js` 是平台入口：先加载 `/api/toefl/bootstrap` 中的当前账号和学习状态，再顺序加载匿名题目、判分、学习与应用脚本。服务只将 `clients/cloud-client.js` 单独映射为 `/web/toefl-cloud.js`，不会公开其他客户端、模板或原 Worker。独立匿名预览继续使用原有入口，不加载该桥。

| 接口 | 合同 |
| --- | --- |
| `GET /api/toefl/bootstrap` | `{me:{id,username,role,aiReady:false},state:{items:[{key,value,revision}]}}` |
| `GET /api/toefl/state` | `{items:[{key,value,revision}]}`，只返回当前会话账号 |
| `PUT /api/toefl/state` | 接收 `{key,value,revision}`；版本冲突返回 `409`，客户端读取当前状态后按原合并逻辑重试 |
| `GET /api/me` | 验证当前登录会话；失效返回 `401` |

所有请求携带页面最初核验的 `X-Account-ID`，用于阻止旧标签在账号切换后写入新账号；该头不提供授权，真实身份始终由服务端会话确定。状态仅接受原托福历史、草稿、词汇、学习排程及兼容历史五种键。原冲突合并、离线待办与草稿取消标记继续保留。

本地学习状态使用 `school-exam-platform:account:<服务端账号ID>:toefl:<原始键>`；录音使用独立的 `SchoolExamPlatform:account:<服务端账号ID>:toefl:recordings:v1` 数据库。切换账号不会读取其他账号或之前匿名预览的数据，也不会自动迁移、清除这些旧数据。退出与会话失效不删除本地录音。

本轮题库仍为原创匿名样例。口语录音保存在当前浏览器，并明确显示“录音已保存在此浏览器”；不显示已云同步，不上传到尚未实现的录音接口，也不启动录音上传重试。外部 AI 评分、完整真实题库、原云站账号迁移和公网部署仍未接入。跨设备可读取服务器保存的学习状态，但本机录音不会随状态同步到其他设备。

新增回归验证统一身份请求、账号命名空间、统一退出、保留其他账号与旧数据，以及本机录音能力。模块总计 46 组检查通过只代表替身与匿名环境验证；真实麦克风、外部 AI、Windows 和公网部署仍需各自验证。
