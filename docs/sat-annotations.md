# SAT 准备页与高亮笔记

本轮需求日期：2026-10-22。用户通过 Bluebook 参考截图明确授权更新 SAT `preparing` 页的文案、云朵与沙漏动画，以及考试内的高亮工具栏、下划线和 Notes 侧栏。这是现有考试界面保护约定的限定例外；其余考试布局、配色、字体、答题、计时、检查、保存和完成流程继续受保护，不将管理页主题引入考试页。

本轮不新增公共接口、依赖、账号、云端同步或题库迁移，也不改变独立 SAT 与统一平台的存储隔离方式。

## 准备页

- 标题为 `We're Preparing Your Practice Test`，提示为 `This may take up to a minute. Please don't refresh this page or quit the app.`。
- 云朵在卡片内横向移动。沙漏每 5 秒循环：前 4 秒上层沙量减少、下层沙量增加并落下砂粒，最后 1 秒翻转，再继续漏沙。
- 系统开启减少动画时，云朵与沙漏静态显示；窄屏下标题可以换行，卡片适应可用宽度。
- 动画不控制题目加载或考试计时。实际准备页仍在题目读取完成且至少等待 500 ms 后进入考试，因此题目读取很快时只会短暂出现。

对应实现为 `front-end/sat/js/app.js` 的 `transitionArt()`、`transitionPage()`，以及 `front-end/sat/css/dashboard.css` 的 `.practice-transition--preparing` 专属规则；保存页和完成页不使用这些新规则。

## 高亮、下划线与 Notes

开启 `Highlights & Notes` 后，在文章、题干或选项中选中文字即可创建高亮。工具栏提供黄色、蓝色、粉色、下划线、添加笔记和删除高亮；当前高亮使用对应的加深色标示选中状态。

每条高亮保留自己的文字范围。范围重叠时，渲染按各范围的边界切分文字，重叠部分以 darken 方式逐个 RGB 通道取最小值，不截断或覆盖已存高亮。参考图的基础蓝色 `#D6EAFD` 与粉色 `#F8D7F2` 因此叠为 `#D6D7F2`。更换颜色或删除一条高亮后，其他高亮仍保留原范围。重叠部分只显示最后一条带下划线的高亮所设线型。

下划线菜单支持实线 `solid`、虚线 `dashed`、点线 `dotted`，也可关闭下划线。旧记录中的布尔值 `true` 按实线显示，`false` 或未设置按无下划线显示。

`Add note` 为当前高亮添加一条笔记；已有笔记时打开原笔记。Notes 侧栏显示该高亮的原文摘录、跟随高亮颜色的卡片标题、自动增高的文本框与删除按钮。正文输入后随当前练习自动保存在浏览器。侧栏可收起、重新展开，也可用阅读分隔条调整打开笔记时的阅读区域比例。

桌面侧栏宽 230 px，卡片间距 8 px；分隔条限制最小阅读宽度，避免拖动后正文消失。600 px 以下侧栏覆盖阅读区，不再占用两栏宽度，收起后继续阅读。此适配仅涉及 Notes，不重排原有考试页头和答题界面。

删除笔记先显示 `Delete This Note?` 确认：`No` 保留笔记，`Yes` 只删除笔记，高亮与下划线继续保留。删除高亮则同时删除依附该高亮的笔记。切换题目后，侧栏只显示当前题目的笔记。

对应结构与交互位于 `front-end/sat/html/index.html`、`front-end/sat/js/exam.js` 和 `front-end/sat/css/exam.css`。工具栏、下划线菜单及 Notes 侧栏使用独立选择器，不通过全局管理主题改写考试界面。

`front-end/sat/js/material-text.js` 同时修复了材料按段落或列表重新排版时丢失整段高亮的问题：文字切片保留共同祖先的高亮与原文格式外壳，文字内容与范围偏移保持不变。

## 保存结构与兼容

笔记依附于单条高亮，不另建独立笔记库：

| 字段 | 用途 |
| --- | --- |
| `qs.highlights[]` | 每题高亮列表；沿用 `id`、`block`、`start`、`end`、`color` 与 `underline` |
| `h.note` | 笔记正文；字符串存在即表示已添加笔记，空字符串也保留笔记卡片 |
| `h.noteCreatedAt` | 首次添加笔记的时间，用于排列卡片 |
| `qs.notesExpanded` | 当前题目的 Notes 侧栏是否展开 |
| `state.notesSplit` | Notes 展开时的阅读区域比例；普通阅读比例继续使用原 `state.split` |

新增字段为可选值，旧高亮与旧练习记录仍可读取；本轮没有调整 IndexedDB 版本或数据库结构。

`Save and Exit` 保存完整运行快照，`Resume` 从快照恢复高亮、笔记正文及侧栏状态。完成练习时，每题的 `answers[questionId].highlights` 也保留高亮及其中的笔记字段。**当前成绩复盘界面未新增笔记阅读功能**：数据保留不代表完成后的 Review 页面已经能查看这些笔记。

所有记录仍仅保存在当前浏览器，没有按账号隔离、跨浏览器、跨设备或云端同步。清除浏览器站点数据会影响这些记录。下列命名空间沿用原约定，本轮不读取或迁移另一入口的个人记录：

| 入口 | IndexedDB | 运行状态 localStorage | 界面偏好 localStorage |
| --- | --- | --- | --- |
| 独立 SAT | `SATPracticeDB` | `sat-reading-practice-v1` | `sat-ui-preferences-v1` |
| 统一平台 `/sat/` | `SchoolExamPlatform:sat:v1` | `school-exam-platform:sat:runtime:v1` | `school-exam-platform:sat:ui:v1` |

统一平台的名称映射继续由 `front-end/web/sat-bridge.js` 实施。真实题库和学生记录不通过 Git 共享，测试应使用原创合成题和独立浏览器来源。

## 人工验证步骤

以下是可复现步骤与预期结果，不表示这些检查已全部通过。实际执行结果应另在本轮交付说明中记录。

1. 按 README 在空闲端口启动本机服务，在独立浏览器来源导入 `front-end/sat/data/examples/synthetic-practice.json`，创建练习并进入 Timing 页面。
2. 点击 `Next`，检查准备页标题、提示和卡片。题目读取较快时页面只短暂显示；完整检查动画可在独立调试环境临时延迟题目读取，观察至少 5 秒，确认沙量变化、翻转与云朵移动，再撤销调试延迟。系统开启减少动画后再次检查，应静态显示，不影响进入考试。
3. 进入考试，开启 `Highlights & Notes`，分别在文章、题干与选项中选择文字，检查三个颜色和当前高亮的加深状态。连续创建两个部分重叠的范围，检查重叠处混色；更换其中一条的颜色、再删除该条，检查另一条的原范围仍完整。
4. 为高亮依次选择实线、虚线、点线和无下划线，检查线型；用键盘打开菜单、移动选项、选择并按 `Escape` 关闭。若有旧 `underline: true` 的合成练习快照，恢复后检查其按实线显示。
5. 给至少两条不同颜色的高亮添加笔记，输入多行正文，检查摘录、卡片颜色、文本框增高和当前笔记选中状态。切题后再返回，检查各题笔记分开显示；收起、展开 Notes 并调整阅读分隔条，检查侧栏和比例。
6. 删除一条笔记，先选 `No`，检查笔记仍在；再次删除并选 `Yes`，检查笔记消失而对应高亮仍在。给另一条高亮保留笔记，再删除该高亮，检查高亮与关联笔记同时消失，其他范围和笔记继续保留。
7. 保留至少一条带笔记的高亮，使用 `More → Save and Exit`，刷新后从 Dashboard 选择 `Resume`，检查正文、颜色、线型、Notes 展开状态及阅读比例恢复，并检查答案和计时恢复行为。
8. 完成合成练习，检查正常到达结果页。需要核对存储时，在浏览器开发者工具中检查该次 attempt 的 `answers[questionId].highlights` 包含笔记字段；不要将当前 Review 页面没有笔记阅读入口误判为该字段已丢失。
9. 在窄屏和减少动画设置下重复关键操作，检查工具栏、下划线菜单和 Notes 控件仍能使用；分别从独立 SAT 与统一平台入口运行合成练习，检查两套命名空间继续独立。

准备页延迟调试只能用于隔离环境，不提交为实际等待逻辑。验证不得使用或提交真实题目、原浏览器个人记录或学生信息。

## 本轮实际检查

2026-10-22 在 macOS Chrome 的独立浏览器上下文中，使用原创合成题分别完成独立 SAT 和临时统一平台 `/sat/` 的浏览器回归：重叠范围、三种下划线、多条笔记、纯文本输入、删除与取消、收起展开、跨题切换、Save and Exit 后刷新并 Resume、答案保留、旧布尔下划线、整篇高亮、文学及列表格式、完成练习与笔记字段留存均通过。375 px、700 px 与桌面尺寸的 Notes 布局已检查；未验证 Windows、Safari 或其他浏览器。

15 项 Python 平台与题目格式检查、首页数据模型检查、修改过的 JavaScript 语法和差异空白检查通过。准备插画在独立渲染中观察过翻转、移动和系统减少动画状态。测试服务、浏览器上下文和临时题库均独立于真实资源。

可选浏览器回归脚本为 `back-end/tests/sat-annotations.browser.cjs`，需要 Node.js、Playwright 及 Chrome；这些仅用于开发检查，不是网站运行依赖。本轮使用现有的 Codex 捆绑运行环境，没有新增或安装项目依赖。环境已具备时，在仓库根目录运行：

```sh
node back-end/tests/sat-annotations.browser.cjs
```

脚本默认自建只读临时端口并使用独立浏览器上下文，不读取既有浏览器历史。`PLAYWRIGHT_CHROMIUM_EXECUTABLE` 可选择已有的 Chromium 路径；`SAT_BROWSER_TEST_URL` 可指定**隔离、空题库测试服务**的 `/sat/` 入口，不应指向正式或个人题库环境。
