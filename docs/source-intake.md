## 接入步骤

1. 确认源码完整性、依赖锁文件、启动说明和资源引用。
2. 检查是否包含真实密钥或运行数据；配置改为示例变量，记录变量用途。
3. 在独立功能分支导入并记录来源，尽可能保留可追溯的原始版本信息。
4. 先复现主要操作：进入题目、作答、提交、查看结果；记录现有行为。
5. 补充真实的安装、运行和检查命令，以及实际验证的平台。
6. 更新 architecture.md，提出与公共身份、答题记录的接口对接方案。
7. 通过 PR 检查后纳入主分支。

只有网站网址时，可以检查界面和使用流程，但无法据此取得完整后端源码、数据库结构或部署配置。
