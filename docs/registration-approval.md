# 管理员站内审批注册（Cloudflare）

## 当前决定与范围

2026-10-25 用户将尚未发布的邮件审批方案改为**所有管理员账号共享可见的站内注册申请**。无需 Resend API Key、发信域名或邮箱配置；网站域名不变。不发邮件、短信或操作系统推送。

1. 新用户在登录页选择注册，填写账号、显示名称、密码和确认密码。
2. 服务端保存待审批申请，不创建可登录用户、不签发会话。
3. 所有有效管理员在「账号管理 → 注册申请」查看同一份列表，可通过或拒绝。
4. 任意一位管理员通过后才创建普通学生账号；拒绝不创建账号。不是每位管理员都需同意。
5. 多管理员同时处理，以首次成功操作为准；其他操作提示申请已被处理并刷新列表。
6. 原有账号无需重新审批。Python 本机后端不增加注册功能，新前端兼容其原登录和账号管理。

**人工审批不等于“一人一号”。** 当前仅保证同一用户名不能重复占用，未加入学号、身份名单或每人注册码。申请者换用户名仍可能再次申请，管理员批准前须自行核实身份；显示名称由申请者填写，不是验证过的姓名。

## 管理员使用

从首页头像进入账号管理，查看注册申请待处理数量。列表支持待审批、已通过、已拒绝和全部状态；通过或拒绝前有确认对话框。所有管理员读取同一共享队列，不为每人复制申请。

页面打开时加载，重新聚焦/回到可见时刷新，并在可见且登录有效时每 30 秒刷新；也可手动刷新。这是站内列表提醒，不是离线推送。新任管理员同样能看到共享申请；被停用、降级或退出的账号不能继续审批。

申请提交成功只表示已存入服务器等待处理，不表示注册完成。批准后用户返回登录页，用原申请账号与密码登录。当前没有给申请者自动发送处理结果；请管理员通过既有联系渠道告知。忘记密码仍由管理员重置，不应通过重复注册解决。

## 接口与安全边界

| 接口 | 行为 |
| --- | --- |
| `GET /api/auth/registration-config` | 返回 `{enabled, mode:'admin'}`；存在有效管理员才启用注册，不公开管理员名单 |
| `POST /api/auth/register` | `{username,displayName,password}`，成功返回 202 `{pending:true,message}` |
| `GET /api/admin/registrations` | 管理员读取共享申请和待处理数量；不返回密码、散列或会话凭证 |
| `POST /api/admin/registrations/{id}/approve` | 空对象 `{}`；管理员批准，原子创建 student 并记录处理结果 |
| `POST /api/admin/registrations/{id}/reject` | 空对象 `{}`；管理员拒绝，不创建用户 |

管理接口要求真实有效管理员会话及页面账号绑定，写操作要求同源 Origin、JSON 与严格字段校验。隐藏学生菜单不是访问控制；后端独立验证权限。GET 不产生批准/拒绝副作用。旧邮件 token 核对、批准接口已退出使用，不能绕过管理员登录审批。

密码仍使用现有 PBKDF2-SHA256 600,000 次加盐散列；待审批申请与正式 users 分离，批准才创建用户。申请人不能指定角色、启用状态或审批人。处理动作与账号创建、审计日志在同一事务中完成，防止竞态、重复批准或半完成状态。所有既有单会话、权限隔离、改密和停用撤销规则保留。

## 数据与迁移

现有生产账号、会话、学习记录不删除或重建。数据库迁移必须可重复执行，并兼容旧 v1 生产库和前一轮未发布的邮件审批开发库。旧邮件申请不自动变为已批准用户，旧邮件链接失效；原发信环境变量不再参与注册开关。

申请数据只存私有服务端，不写入前端静态文件或 Git。注册和待审批容量有服务端限制，失败与重复请求也计入限额；并发散列保留短租约，异常不能永久占用用户名。已拒绝的用户名允许重新申请，仍受限流；这不是封禁用户的机制。

待审批申请有效期为 7 天，到期删除后可重新申请。已处理历史保留 30 天且最多 3,000 条；处理后立即清除申请中的密码散列。待审批及正在散列的申请合计最多 500 条。注册限额为每 IP 每小时 5 次、全局每 10 分钟 20 次、全局每天 100 次，限流返回 429 及 `Retry-After`。这些限制也会影响共用校园出口 IP 的用户，应分批申请；它们用于控制滥用，不代表能确认真实身份。

## 本机验证

```sh
node --test --test-concurrency=1 tests/registration.test.mjs tests/registration-runtime.test.mjs
npm run test:registration-browser
npm run build
npm test
npm run test:browser
npx wrangler deploy --dry-run
```
