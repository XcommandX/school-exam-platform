## 合并冲突

合入 `main` 无文本冲突，实际带入 `front-end/web/styles.css` 的绿色卡片修改。

合入 `toefl` 产生 25 个 add/add 冲突：24 个位于 `back-end/toefl/`，1 个为 `docs/toefl-productization.md`。原因是托福此前从 `72ab41d` 以文件复制方式接入，双方 Git 历史没有共同的托福文件版本。合并前本地 `back-end/toefl/` 与 `72ab41d` 逐文件相同，无额外模块内补丁；因此冲突采用最新 `98aa9c7`，统一平台适配仍保存在模块外。解决后的 `back-end/toefl/` 与远端版本逐字节一致。
