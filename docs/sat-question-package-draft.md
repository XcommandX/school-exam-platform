# SAT 题目包：耕读格式比较与新草案

日期：2026-10-23。状态：供团队评审的 SAT 专用草案，未接入运行中的网站。

## 结论与范围

按最新决定，题目包按考试和题目类型分别设计、存放，不再要求 SAT、TOEFL、AP 使用同一个题目模型。本轮只设计 SAT：读写四选一、数学四选一、数学填空（SPR）分别成包；文字统一 Markdown，数学公式使用 LaTeX。

新草案保留旧设计中有用的稳定 ID、修订、独立答案解析、资源清单与精确数值答案；去掉跨考试需要的多层 Part/Interaction、录音、作文 rubric 等抽象。普通专题包不强制附整卷蓝图，组卷与计时另存引用配置。

表格、图表和坐标系的结构化渲染方案仍待定。本次只确定有序内容块和静态图片引用，不提前绑定绘图库或 Desmos。

可直接查看 [格式合同与三个原创样包](drafts/sat-question-packs/README.md)。原网站、现有 v1 校验器和导入器保持当前实现；新样包不可直接导入旧引擎。

## 比较依据

本次读取本机 `耕读合集/` 全部 280 个 JSON：276 个题包、4 个审计清单。题包合计 8,309 道题，未把审计清单误当题包，也未向 Git 保存题目正文、图片或原始来源清单。

“之前的格式”分两层，避免只比较已运行的 v1：

1. [当前题目格式](question-format.md)、`shared/question-set.schema.json` 和 `shared/question_schema.py`：正在使用的 v1，SAT 只接入读写四选一。
2. 本地 `docs/exam-pack-strategy` 分支提交 `5315baa` 的 `docs/所有题目包结构策略.md`、`docs/drafts/exam-packs-v2/CONTRACT.md` 及 `sat-math/`：之前跨考试 v2 草案。该分支未合入本轮，只作比较；其中 SAT 数学已有四选一、SPR、静态图与互动图占位设计。

来源的 `schema_version: 2` 与项目的 `schemaVersion: 1`、旧跨考试 `2.0-draft` 是三个不同协议的版本标识，不能按数字大小直接互换。

## 格式异同与取舍

| 方面 | 耕读 JSON | 当前 v1 | 旧跨考试 v2 草案 | SAT 新草案 |
| --- | --- | --- | --- | --- |
| 物理结构 | 单 JSON，题目与图片 base64 同包 | 题集 JSON，私有图片分存 | pack / assessment / items / solutions / assets | pack / items / solutions / assets，试卷配置另存 |
| 范围 | SAT RW、Math，可混合 | SAT RW 四选一 | SAT/AP/TOEFL 共用外层与交互层 | 仅 SAT，同科目同作答类型成包 |
| 题目身份 | 独立来源 question_id，另有显示题号 | 题目 ID 归属题集，多从顺序生成 | 稳定 itemId + revision | 保留独立稳定 ID 与修订，不依赖顺序 |
| 正文 | text 与 html 双份 | 纯文本、UTF-16 样式范围，有限 Markdown | text 默认 plain，可选 Markdown 与 math 块 | 所有文字明确 Markdown，公式内嵌 LaTeX |
| 混排 | 任意 HTML、图片、公式 DOM | 每题单个 visualStimulus | materials / parts / interactions，多种 block | 扁平题目，有序 Markdown/image 块，选项和解析也可含图 |
| 选项 | label / text / html | 字符串数组 | 稳定选项 ID + 内容块 | 稳定选项 ID；显示字母与答案引用分开 |
| 填空答案 | 单字符串，可能含逗号、分数、小数 | 不支持 | 数值规则与输入规则分开 | SPR 独立包，精确有理数 + 审核过的小数写法 |
| 答案解析 | 与题目同存，有来源状态 | correctOption / explanation | solutions 独立，Part 关联 | solutions 独立，直接关联题目 ID 与修订 |
| 资源 | URL、状态、MIME、SHA256、base64 | 本机相对图片路径 | 完整附件清单与摘要 | 独立本地附件 + 摘要清单，不把 base64 重复放正文 |
| 表格/坐标图 | HTML 表格或图片，公式带 MathQuill | 简单结构表格，chart 仍是图片 | 表格块、静态 SVG、互动图候选 | 图片先保留；结构表格、数据图和坐标模型待定 |

耕读值得借鉴的是包级资源清单、来源追踪、独立题号/科目/作答类型和答案状态。图片 base64 很适合原始归档与恢复，但不适合长期重复存于许多包：此次 665 条资源记录去重后只有 620 个来源。

不照搬 HTML 双份正文、MathQuill 编辑器 DOM、逗号答案串、按抓取结果标记的 complete/confirmed，也不照搬来源混合卷的模块含义。新格式应让缺失资源、待审答案和无解析都显式可见。

## 转换顺序与验收条件

本次尚未把全部真题转换成新格式。后续转换器应先做一份可审查映射，再批量生成：

1. 保留原 JSON，识别科目与 `choice` / `response`，按三种 SAT 包拆分；记录原包、原题号和模块号映射，不改变原卷顺序含义。
2. 对 HTML 进行受控解析。提取 MathQuill `latex-data` 后整体替换公式 DOM；保留语义下划线、段落和诗歌换行，丢弃编辑器节点。只剥标签不可接受。
3. 将文字转 Markdown，公式转 LaTeX，图片转资源 ID。图片、表格可以出现在材料、提问、选项或解析中；图片型公式暂不猜写。
4. 对表格/图表分别登记处理方式。简单表格可另做 Markdown/结构表格试样；暂存图片时必须保留来源、文字替代和待审状态，不能丢行列信息后声称完成。
5. 四选一将来源 A–D 映射到稳定 optionId。SPR 将多答案串分解为明确候选，再核对精确值、小数精度和输入规则；来源 confirmed 初次映射 needs-review。
6. 题目与解答分开，缺解析标 missing；按白名单复制出处，不带入学生作答。原题包未发现学生作答字段，但删除清单含姓名、部分坏 URL 含作者本机路径，因此真实归档与报告仍仅留本机。
7. 校验题数守恒、稳定 ID、题型、答案关联、公式数及全部资源引用；人工查看下划线、图表、图片选项和公式密集题。完整批量迁移前另行实现并验证渲染器、SPR 判分与旧引擎适配。

当前原创样包与校验器只用于审核设计。后续不可直接调用 v1 `normalize_question_set` 来转换新包：其白名单会拒绝或丢掉不支持字段，SAT Math 也不被当前引擎接受。

## 图片下载与离线包装

原正文有 667 个 img 引用，与包级清单的 620 个唯一来源完全对应：608 个有效网络资源、10 个来源已标失效的网络资源、2 个内联 SVG。清单共有 653 条 base64 嵌入记录，全部与原 SHA256 相符；同一 URL 没有不同嵌入内容。

使用 [资源整理脚本](../scripts/package_sat_images.py) 从原 JSON 扫描、联网下载、验证并去重。实际下载统计以本机生成的报告为准；不能把 base64 恢复计为网络下载成功。来源失效的 10 个链接含作者本机临时文件路径，保留缺失报告，不能用假图替代。

本机原始 `耕读合集/` 和 `耕读合集.zip` 已列入 Git 忽略。用户本轮明确要求在合集目录打包，因此此次资源在该目录整理；不移入网站运行题库，也不提交真实素材。这是对默认 `private-data/` 存放位置的本轮例外，后续导入网站仍应遵循私有资源规则。

下载工具只处理资源归档，离线 JSON 仍为来源协议，不是本页的新 SAT 包格式。离线副本仅改变已成功落盘资源的引用和图片存放方式，原 JSON 不改。缺图文件不得标为全部资源完整；完整结果及启动参数见脚本帮助与本机包内说明。

2026-10-23 本机整理结果：原 620 个来源中，602 个直接下载、6 个通过备用地址下载、2 个内联 SVG 解码，10 个确认 404。6 个备用 URL 也均实际请求；最终得到 608 张网络原图与 2 份内联 SVG，共 610 份去重资源，网络图片均与源 JSON 的摘要相符，本次无需 base64 恢复。

本机交付位于 `耕读合集/`：`assets/`、`离线题包/`、`图片清单.json`、`下载报告.json`、`离线包说明.md`、`耕读合集-图片离线包.zip`。ZIP 为 40,416,462 字节、889 个条目；10 个缺失地址涉及 4 个题包，报告明确 `fully_offline: false`。这份 ZIP 已打包全部可获得资源，不能称为无缺图的完整题库。

复跑默认复用摘要验证通过的资源；`--refresh` 会重新联网：

```sh
python3 scripts/package_sat_images.py --source "耕读合集"
python3 -m unittest discover -s tests -p 'test_package_sat_images.py' -v
```

如本机 Python 未配置可信 CA，可用 `--ca-file` 指定已有的可信证书包，TLS 验证保持开启，不修改永久代理或证书设置。
