# SAT PDF 题库

此目录由用户指定的508份可编辑PDF转换，题目版与答案版合并，再按明确年月、套号、地区和版本组合英语与数学。最终183个题集、10558题，其中51个完整SAT。

- 入口与来源：[合并说明](合并说明.md)
- 批处理、格式与检查：[转换文档](../../../../../docs/sat-pdf-conversion.md)
- `catalog.json` 为唯一公开索引；`pdf-source-manifest.json` 提供每个PDF到最终题集的映射。
- `source-catalog.json` 仅是原508来源的历史索引，不保证中间生成目录仍在此处。
- 原PDF与未上架生成副本留在忽略的local-data；此目录不含用户作答记录。
- 来源公式及答案仍待审；本次只作本地提交，未推送、合并main或部署。
