# SAT PDF 合并说明

最终公开 183 个带答案题集，共 10,558 题：71 个跨科组合（51 个完整 SAT、20 个部分卷），另保留 112 个无法明确配对的单科来源。

508 份原 PDF 组成 254 对题目版/答案解析版；10,558 道题逐题核对文本、样式、图片及向量特征均一致。纯题目版已并入答案版，最终目录不保留重复的无答案版。没有整卷完全缺答案的来源；一处来源答案与选项不符仍标记待审，不猜答案。

按明确的年月、单一套号、地区及模块版本匹配。不将未标地区与明确地区混为一卷，不猜配去重混卷、Bluebook 或多候选版本。完整卷须英语27+27、数学22+22，保留原题号及32/32/35/35分钟，英语后10分钟休息。其余组合保持Partial Test。

原 PDF 未修改。396 个不再上架的中间生成目录已移出最终目录，保存于忽略的本机审阅归档。`pdf-source-manifest.json` 的 `publishedCollectionId` / `mappedPublishedCollectionId` 指向每份 PDF 对应的最终题集；原来源ID仍用于追溯。`source-catalog.json` 是转换前508来源的历史索引，不是可直接练习的目录。
