# 托福纯源码接入

本目录按仓库规则保存原托福模块的源码、原创匿名样例和检查工具，与 `apps/sat/` 独立维护。供统一入口使用的页面跳转已提供，见 [入口约定](ENTRY_INTERFACE.md)；公共身份与记录 API 尚未实现，原私有云站保持独立。本目录的构建和预览不部署网站。

## 本地运行

需要 Node.js 22.13 或更高版本。模块没有第三方 npm 依赖，无需先安装依赖。

在本目录运行，Windows 与 macOS 使用相同命令：

```sh
node scripts/check-source.mjs
node scripts/build.mjs
node scripts/test.mjs
node scripts/preview.mjs
```

预览地址为 `http://127.0.0.1:8788/`，只监听本机。首页明确标记匿名样例；题目是原创测试材料，听力与口语音频仅为合成提示音，不代表来源原音频。关闭终端或按 Ctrl+C 停止预览。

构建输出位于忽略提交的 `dist/`。`dist/preview` 仅用于匿名界面预览，`dist/cloud-test` 供原有后端回归在内存数据库中运行；两者都不是正式部署包。测试使用替身 AI，不调用外部模型或正式数据库。

## 文件结构

| 目录 | 内容 |
| --- | --- |
| `src/frontend` | 原有界面、判分、学习与录音前端源码，从原 dist 目录迁出；保持原功能代码 |
| `src/cloud` | 原 Worker、评分、同步、账号、页面模板及数据库结构；没有真实部署配置或初始化脚本 |

| `scripts` | 使用相对路径的本地构建、检查和预览 |
| `source-snapshot.json` | 原源码和已有测试的导出摘要，供接入时核对；后续代码修改通过 Git 差异追踪，不覆盖原导出摘要 |
| `SOURCE_MANIFEST.json` | 当前交付白名单与逐文件摘要；不计算清单自身哈希 |

## 上传边界与清单维护

`.gitignore` 默认忽略新文件，只放行逐项审查的源码和匿名样例；当前清单检查同时核对文件摘要、匿名数据和 Git 已跟踪范围，可发现强制加入的清单外文件。它还检查常见访问令牌、私钥、开发电脑路径与破坏性 SQL；静态扫描不能替代人工审查。

修改已有源码后，先审查差异，再运行 `node scripts/check-source.mjs --update` 更新清单摘要。新增文件须明确加入忽略规则和清单；命令不会自动扫描目录收集新文件。构建输出、音频、录音、题库、HAR、密钥及正式部署配置不得加入清单。

## 服务端配置边界

匿名构建和预览无需配置变量，也不需要 Cloudflare 登录。`.env.example` 只说明原 Worker 的变量名，不会自动加载或连接服务。

原 Worker 需要 `DB`（D1）、`ASSETS`（加密资源）与可选 `AI` bindings。`CONTENT_KEY` 为服务端 AES 密钥；`ADMIN_USERNAME`、`PASSWORD_SALT`、`PASSWORD_HASH` 是原系统兼容初始化参数；正式迁移不能用它们重置既有账号。`ENABLE_AI`、`ASSESSMENT_PROVIDER` 和模型名称控制评分服务，Groq 仅在显式配置服务端 `GROQ_API_KEY` 后使用。配置值不得放入浏览器或提交到 Git。

本仓库没有真实 binding 标识、密钥、首次建库或历史清空命令。SQL 文件是结构参考，本地检查只在内存数据库中执行；普通服务器部署、正式资源获取和账号迁移均需独立任务。

## 公共接口的本地适配

`src/integration/platform-adapter.mjs` 提供 `mapQuestion(record)` 和 `mapAttempt(attempt, context, questions)`，落实现有架构草案中的考试命名空间、题目内容版本、独立练习编号、UTC 时间和同账号同版本重试键。

`context.userId` 必须由未来调用方从服务端已验证身份中取得；映射函数本身不提供身份认证。它忽略作答对象自带的用户 ID，并把客户端成绩标为 `client_reported`。正式身份和保存服务未接入，因此当前未实现统一登录、保存接口或跨模块同步，也不宣称已有服务端成绩复核。

题目原始 ID、日期版本及练习原始结构保留。接口名和字段目前只是可测试的适配草案，需与 SAT 负责人确认后冻结。现有前端和云端接口没有因此改名或自动迁移。

## 参考布局与题目编辑

四科答题使用统一的青绿色标题栏、题号计时栏和正文布局。模考页只保留组卷与考试操作，未完成记录在考试记录中查看。错题本单独导航，分为曾答错与手动标记的不熟悉；两种分类可以同时包含同一题。

题目编辑固定为 `toefl-task/1`，字段、版本、资源边界与跨平台命令见 [QUESTION_FORMAT.md](QUESTION_FORMAT.md)。源码工具不连接正式数据库，也不迁移用户作答。


## 首页与考试记录

托福主页融合新版工作台的留白、圆角和卡片层次与原托福的练习操作，使用绿色主卡、真实统计、四项学习工具和最近考试记录。首页以 Start Practice 统一进入专项练习，内部继续保留四科、题型、搜索筛选、计时、随机组卷和作答／解析切换；整套模考单独进入。未完成练习优先显示，返回题库时保留既有科目和筛选。首页保留新版简洁顶部；进入题库、模考、错题、词汇、记录与进度等次级页面后显示绿色导航条，右侧只保留新版学习入口（独立平台预览）、账号菜单与设置，旧搜索／设置／账号工具不再渲染。窄屏导航单独横向滚动，不挤占右侧控件。账号菜单与设置使用现有身份和设备偏好。考试与解析仍使用独立的青绿色考试栏，不受管理页面的暖白背景影响。

完成考试时先保存成绩和同步待办，再清理对应草稿；本地保存或入队失败时保留当前作答供重试，同一考试 ID 不重复写入。成绩已保存但草稿未清理的恢复提交会更新为当前答案，仅对变化的小题更新学习排程；相同录音的评分缓存须与已同步音频摘要一致。刷新后也会从当前考试有效的本地音频恢复已录制标记。成功后清空历史页残留筛选；单科筛选会包括含该科的全科考试，筛选状态可一键清除。同步检查均使用替身服务，本地示范不连接正式账户或云端同步。
